Dán liên kết Google Apps Script Web App để mỗi khi bạn bấm nút "Lưu", hệ thống sẽ tự động thêm ngay 1 hàng mới vào file Google Sheet trên Google Drive của bạn:

• Hoặc bấm "Sao chép dòng dữ liệu" bên dưới để dán thủ công

Mã Google Apps Script Tự Động Thêm Hàng Vào Google Sheet

Thực hiện 3 bước đơn giản trên file Google Sheet của bạn để tự động hóa 100%:

  1. Mở file Google Sheet, vào menu Tiện ích mở rộng (Extensions) > Apps Script.
  2. Dán đoạn mã bên dưới vào file Code.gs và bấm Lưu (Ctrl + S).
  3. Bấm nút Triển khai (Deploy) > Tùy chọn triển khai mới (New deployment) > Chọn loại Ứng dụng web (Web app) > Mục "Ai có quyền truy cập" (Who has access) chọn "Bất kỳ ai" (Anyone) > Bấm Triển khai rồi sao chép URL Web App dán vào hệ thống.
function doPost(e) {
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheets()[0]; // Lấy trang tính đầu tiên
    var contents = e.postData ? e.postData.contents : "{}";
    var data = JSON.parse(contents);

    var chi = data.expense !== undefined ? data.expense : (data.chi || 0);
    var tang = data.income !== undefined ? data.income : (data.tang || 0);
    var conLai = data.balance !== undefined ? data.balance : data.conLai;
    var thoiGian = data.time || data.thoiGian || "";

    // Ghi đúng chuẩn 4 cột: Số tiền chi | Số tiền tăng | Số tiền còn lại | Thời gian
    sheet.appendRow([
      chi === 0 ? "" : chi,
      tang === 0 ? "" : tang,
      conLai,
      thoiGian
    ]);

    return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  return ContentService.createTextOutput("Webhook Google Sheet đã sẵn sàng hoạt động!");
}

Hướng Dẫn Bật Đồng Bộ Trực Tiếp Từ Google Sheet

Để hệ thống tự động tải số liệu tức thì từ liên kết Google Sheet của bạn mà không cần đăng nhập Google, bạn làm theo 3 bước đơn giản:

  1. Mở file Google Sheet bằng cách bấm nút "Xem Google Sheet" ở góc trên bên phải.
  2. Ở góc trên cùng bên phải của Google Sheet, bấm nút "Chia sẻ" (Share) màu xanh.
  3. Tại mục "Quyền truy cập chung", chọn "Bất kỳ ai có đường liên kết" (Anyone with the link) với quyền "Người xem" (Viewer) rồi bấm Xong.
Mẹo: Sau khi bật chia sẻ xong, bạn chỉ cần bấm nút "Làm mới & Đồng bộ", biểu đồ và số dư thu chi sẽ được cập nhật tự động 100%!
